README – SAMKO Padel Gear
Over dit project

Dit is mijn eindejaarsproject waarbij ik een webshop heb gemaakt voor een fictief bedrijf: SAMKO Padel Gear. Het idee is een start-up die padelmateriaal verkoopt zoals rackets, schoenen en accessoires.

De website is volledig opgebouwd als een echte webshop met verschillende pagina’s en een werkende winkelmand.

Wat is SAMKO?

SAMKO is een merk dat ik zelf heb bedacht. Het concept is dat iedereen op een betaalbare manier toegang moet hebben tot goede padelspullen. De focus ligt op sport, kwaliteit en een simpele maar moderne webshopervaring.

Hoe de website werkt

De website bestaat uit meerdere pagina’s:

Homepagina

Op de homepagina krijg je meteen een introductie van SAMKO. Er is een grote hero-afbeelding met een knop die je naar de shop brengt. Ook zie je verschillende merken zoals Nike, Adidas en ons eigen merk SAMKO.

Shop

Dit is het belangrijkste deel van de website. Hier staan alle producten netjes verdeeld per merk:

Nike
Adidas
Bullpadel
SAMKO (eigen merk)
Accessoires

Bij elk product kan je op “In winkelwagen” klikken om het toe te voegen.

Missie en visie

Hier leg ik kort uit waar SAMKO voor staat. Het idee is dat sport toegankelijk moet zijn voor iedereen en dat kwaliteit niet altijd duur hoeft te zijn.

Contact

Een simpele contactpagina met een telefoonnummer en e-mail zodat klanten ons kunnen bereiken.

Winkelwagen

Hier komen alle producten die je hebt toegevoegd terecht. Je ziet:

alle producten die je hebt gekozen
de totaalprijs
een knop om alles leeg te maken
een knop om af te rekenen (simulatie)
Functionaliteiten
Winkelmand

Als je op “In winkelwagen” klikt, wordt het product opgeslagen in de browser (localStorage). Daardoor blijft je winkelmand ook bestaan als je de pagina herlaadt.

Cookie banner

Wanneer je de website voor het eerst bezoekt, krijg je een cookie melding. Je kan kiezen om cookies te accepteren of te weigeren en dat wordt ook onthouden.

Interactie

Alles werkt met JavaScript:

producten toevoegen
winkelmand tonen
totaalprijs berekenen
cookies opslaan
Technologieën

Ik heb gebruikt:

HTML voor de structuur
CSS voor het design
JavaScript voor de functionaliteit
LocalStorage om data op te slaan in de browser
Gebruik van AI

Tijdens dit project is er gebruik gemaakt van AI als ondersteuning. Dit werd vooral gebruikt om hulp te krijgen bij het oplossen van problemen in JavaScript, het verbeteren van code en het duidelijker structureren van bepaalde onderdelen van de website. Alle beslissingen en het uiteindelijke ontwerp zijn wel door mij zelf gemaakt.

Wat ik eruit geleerd heb

Door dit project heb ik geleerd hoe een echte webshop in elkaar zit. Vooral het werken met JavaScript en localStorage was interessant omdat je zo echt data kan laten “onthouden” zonder database.

Toekomstige uitbreidingen

Als ik dit project verder zou uitbouwen zou ik nog toevoegen:

een echte betaalfunctie
login systeem
database voor producten
betere mobiele versie
Eindconclusie

Het is een simpele maar volledige webshop die goed laat zien hoe een start-up website kan werken. Alles is zelf opgebouwd en werkt zonder backend.
